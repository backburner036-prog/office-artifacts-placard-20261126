A museum placard for an ordinary office object, treated as an ancient artifact
from a lost civilisation — a make.fun entry for the
[Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2).

## The placard

> Sticky Note, 1994. Paper, adhesive, faded ink. A prayer slip left on a monitor by the Copy Clerks, asking the gods for toner. Donated by the estate of K. from Accounts.

## Run

```sh
python3 main.py
```

Writes exactly one line (168 characters) to `/output/entry.txt`: catalogue date,
material, and donor included, as a dry-witted museum label demands.
